Setup Guide

Get your MoyooCreates store fully live in about 20 minutes. No coding needed — just paste and go.

1

Open both files in a browser right now

Your store is already working in demo mode. Just double-click index.html to see your storefront. Double-click admin.html to see your seller dashboard. No internet required for this.

✅ In demo mode, you can add/edit products, browse the store, and see how everything looks — but payments won't go through yet.
2

Create a free Firebase account

  • Go to console.firebase.google.com → sign in with Google
  • Click "Add project" → name it "moyoocreates" → Continue
  • On the left sidebar → click Firestore Database → Create database → Start in production mode → Choose a location (e.g. europe-west1) → Done
  • On the left sidebar → click Authentication → Get started → Enable Email/Password → Save
  • Still in Authentication → click Users tab → Add user → enter your email and a strong password. This is your seller login.
3

Get your Firebase config keys

  • In Firebase → click the gear icon (top left) → Project settings
  • Scroll down to "Your apps" → click Web (</>)
  • Register app → name it "moyoo-web" → click Continue (skip Firebase hosting)
  • You'll see a block of code with your keys — copy these values:
apiKey · authDomain · projectId · storageBucket · messagingSenderId · appId
4

Get your Paystack keys

  • Go to dashboard.paystack.com → sign up (it's free)
  • On the left → Settings → API Keys & Webhooks
  • Copy your Public Key (starts with pk_test_ or pk_live_)
  • Use test keys first to make sure everything works before going live
💡 For Paystack to send payment confirmations to your store, you need to host your files online (see Step 6) and set the Webhook URL there.
5

Paste your keys into the HTML files

Open index.html in a text editor (like Notepad or VS Code). Scroll to the very bottom and find:

const CONFIG = {
  firebase: {
    apiKey: "YOUR_FIREBASE_API_KEY",  ← replace this
    ...
  },
  paystackPublicKey: "pk_test_...",  ← replace this
  isDemoMode: true  ← change to false
}

Do the same in admin.html — same CONFIG block at the bottom. Change isDemoMode to false in both files when done.

6

Host your files online (free options)

To use Paystack payments and share your store publicly, upload your files to a hosting service:

  • Netlify (easiest): Go to netlify.com → drag your folder onto the page → done. You get a link like moyoo.netlify.app
  • GitHub Pages (free forever): Create a GitHub account → new repository → upload files → enable Pages in settings
  • Vercel: vercel.com → Import project → upload folder
7

Set up Paystack Webhook (for email alerts)

Once your site is live online, go to Paystack dashboard → Settings → API Keys & Webhooks → scroll to Webhook URL → enter:

https://YOUR-SITE-URL.netlify.app/api/paystack/webhook

⚠️ Note: The Paystack webhook (which sends emails to you and your buyer) requires the Next.js backend we built earlier. For the plain HTML version, Paystack payments will still work — stock will update and orders will save — but automatic email alerts require the Next.js version or a small backend service like Pipedream or n8n.

8

Add your first real product

  • Open admin.html → log in with the email/password you set in Firebase Auth
  • Click + Add Product
  • Fill in: brand, name, description, price (in ₦), units in stock
  • For the image: upload a photo to imgbb.com or Cloudinary (both free) and paste the URL
  • Save — it appears on your storefront immediately!

Need help?

If you get stuck on any step, the most common issues are:

  • Products not showing — make sure Firestore is enabled and isDemoMode is false
  • Can't log into admin — make sure you created a user in Firebase Auth → Users tab
  • Payments not working — make sure your Paystack key is correct and isDemoMode: false
  • CORS errors — you must open the file via a web server (Netlify/Vercel), not from your local Desktop
